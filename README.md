# 24cell-torus-resonance-audit
Scripts using the 24-cell torus theory

Scripts:
reaccom9.py
Reactions in the terminal; ignores standard conditions and only considers the specified molecules; option -h for usage help
reac4.py
Live reactions and molecule view with displayed particles
checkx2de.py
Runs various tests, makes predictions, and outputs a particle table
partx2de.py
Additional tests
allp.py
Visualization of the tori
lhc.py
Particle accelerator simulation
